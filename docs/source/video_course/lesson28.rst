レッスン28：Raspberry Pi Pico WをWiFiに接続
=============================================================================

このチュートリアルでは、Raspberry Pi Pico WとPC間のクライアントサーバー関係の設定をWi-Fi経由で行います：

* **はじめに**: 目標は、Raspberry Pi Pico WをWi-Fiに接続し、PCとのクライアントサーバー関係を確立することです。
* **クライアントサーバー関係の理解**: マクドナルドの例えを使ってコンセプトを説明します。ここではPCがクライアントで、Pico Wがサーバーとなります。
* **Raspberry Pi Pico Wをサーバーとして設定**: Wi-Fiに接続し、IPアドレスを取得し、UDPサーバーを設定する方法を説明します。
* **PC上でクライアントを作成**: PCクライアントがRaspberry Pi Pico Wサーバーにコマンドを送信するコードを提供します。
* **データの送受信**: サーバーがクライアントコマンドを解読し、応答を送信する方法を示します。
* **実践デモンストレーション**: サーバーとクライアントを実行し、データ交換を行います。Pico WはOLEDに自身のIPを表示します。
