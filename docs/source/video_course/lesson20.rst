レッスン20：MicroPythonでDHT11温湿度センサーを使用する
=============================================================================

このチュートリアルでは、Raspberry Pi Pico WでDHT11センサーを使用して温度と湿度を測定する方法について説明します：

* **はじめに**: DHT11センサーを使用して温度と湿度を測定することに焦点を当てます。
* **前回のレッスンの復習**: デジタル書き込み、アナログ書き込み、センサー読み取りのレビュー。
* **コンポーネントの紹介**: SunFounder KeplerキットからのDHT11センサーを紹介します。
* **コードの説明**: ライブラリをインポートし、GPIOを設定し、センサーを初期化し、ループでデータを読み取ります。
* **実践デモンストレーション**: コードを実行し、リアルタイムの温度と湿度の読み取りを観察します。
* **出力のフォーマット**: 摂氏と湿度の出力をフォーマットし、度記号を表示します。
* **宿題**: 摂氏と華氏を切り替えるボタンを追加する課題。
