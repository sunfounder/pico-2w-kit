Lektionen 7: Steuern von 3 LEDs mit einem Potentiometer in MicroPython
===========================================================================

Dieses Tutorial behandelt die Verwendung eines Potentiometers zur Steuerung von drei LEDs (grün, gelb und rot) mit dem Raspberry Pi Pico W:

* **Lösungsüberprüfung der Hausaufgabe**: Rückblick auf den Anschluss eines Potentiometers und von drei LEDs sowie das Abbilden von Messwerten von 0 bis 100.
* **Schaltkreisaufbau**: Schaltplan zum Verbinden des Potentiometers und der LEDs mit dem Raspberry Pi Pico W.
* **Werte lesen und abbilden**: Lesen analoger Werte und Umwandlung der Werte von 432 bis 65.535 auf eine Skala von 0 bis 100.
* **LED-Steuerung**: Verwendung von If-Anweisungen, um LEDs basierend auf der Position des Potentiometers zu steuern (grün für 0-79, gelb für 80-94, rot für 95-100).
* **Praktische Demonstration**: Vorführung des Schaltkreises und des Codes in Aktion.
