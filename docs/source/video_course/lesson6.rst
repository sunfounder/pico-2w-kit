レッスン6：MicroPythonでのif文の理解
=================================================================

このチュートリアルでは、Raspberry Pi Pico Wを使用してMicroPythonでif文と条件分岐を使う方法について説明します：

* **ユーザー入力の処理**: ユーザー入力を取得し、それを異なるデータ型に変換する方法。
* **基本的なif文**: 等価、不等価、比較などの条件を確認するためにif文を使用する方法。
* **条件付きロジック**: if、elif、else文を使用してLEDの状態（オン、オフ、切り替え）を制御する方法。
* **実践的なデモンストレーション**: LED回路をセットアップし、ユーザー入力に基づいて制御する方法を示します。
* **宿題**: ポテンショメーターと3つのLEDを使って回路を作成し、入力範囲に基づいてLEDを点灯させる課題。
