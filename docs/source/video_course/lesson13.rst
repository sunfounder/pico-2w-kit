レッスン13：MicroPythonを使用したユーザー指定のRGB LEDカラー
==========================================================================

このチュートリアルでは、SunFounder KeplerキットとRaspberry Pi Pico Wを使用してRGB LEDを制御する方法について説明します：

* **RGB LEDの制御**: PWMを使用してRGB LEDを制御し、赤、緑、青、およびグラウンドの端子を使って異なる色を実現する方法を示します。
* **配線図とセットアップ**: RGB LEDをGPIOピン13、14、15に接続し、各ピンに220オームの抵抗を使用するための詳細な配線図を提供します。
* **コードの説明**: 各色チャンネルにPWMを設定するMicroPythonコードを提供し、ユーザー入力に基づいて色の制御を可能にします。
* **実践的なデモンストレーション**: 色を入力し、その入力に応じてRGB LEDの色を変更する方法を示します。
* **宿題**: 3つのポテンショメーターを使用して、RGB LEDの色を手動で制御するプロジェクトを拡張する課題。
