マイクロスイッチ
========================

|img_micro_switch|

マイクロスイッチの構造は非常にシンプルです。スイッチの主要な部分は以下の通りです：

|img_micro_switch2|

* 1.プランジャー（アクチュエーター）
* 2.カバー
* 3.動く部品
* 4.サポート
* 5.ケース
* 6.NO端子：通常開
* 7.NC端子：通常閉
* 8.接点
* 9.動作アーム


マイクロスイッチが物体と物理的に接触すると、その接点の位置が変わります。基本的な動作原理は次のとおりです。

プランジャーが解放された状態、または休止状態にあるとき。

* 通常閉回路は電流を通すことができます。
* 通常開回路は電気的に絶縁されています。

プランジャーが押されたり、切り替えられたりするとき。

* 通常閉回路は開かれます。
* 通常開回路は閉じます。
