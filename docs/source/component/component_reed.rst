リードスイッチ
======================

|img_reed|

リードスイッチは、磁場がかかると動作する電気スイッチです。1936年にベル電話研究所のウォルター・B・エルウッドによって発明され、1940年6月27日にアメリカ合衆国で特許番号2264746として特許を取得しました。

**動作原理**

リードスイッチは、シンプルな原理で動作します。鉄とニッケルで作られた2本の金属製リードがガラス管内に封入され、端が重なり合っており、数ミクロンの小さな隙間で分離されています。ガラス管内には、高純度の不活性ガス（例えば窒素）で満たされており、場合によっては高電圧性能を向上させるために真空封止されています。

リードは磁束の伝導体として機能します。磁場がかからない状態では、リードは離れたままです。永久磁石や電磁コイルから発生する磁場にさらされると、リードの端点に反対の極性が誘導されます。もし磁力がリードの自然なばねの張力を超えると、リードが接触し、回路が閉じます。磁場が弱くなるか消失すると、リードの弾性によってリードは再び離れ、回路が開きます。

このシンプルで効果的なメカニズムにより、リードスイッチは磁場によってトリガーされるスイッチングを必要とするさまざまなアプリケーションにおいて非常に信頼性があります。
